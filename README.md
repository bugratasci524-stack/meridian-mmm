# Meridian MMM

Google Meridian ile geo bazlı MMM modeli. Veri: Meridian reposundaki simüle geo_all_channels.csv (40 bölge, 156 hafta, 5 ücretli kanal).

## Kurulum
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

## Çalıştırma
mmm.py dosyasındaki hücreleri (# %%) sırayla çalıştır. Çıktılar outputs/ klasörüne düşer.
